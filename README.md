# FitLog

A modern fitness tracking web application built with Next.js, React, TypeScript, and Tailwind CSS.

## 🔗 Live Demo

[Visit FitLog](https://fit-log-ucza.vercel.app/)

## 📌 Project Description

FitLog is a fitness-focused web application designed with a clean, modern, and responsive user interface. It provides an easy-to-use platform for managing and tracking fitness-related activities.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- Vercel

## ✨ Key Features

- 📊 Fitness activity tracking
- 💪 Manage fitness-related activities
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
- ⚡ Fast and optimized Next.js application
